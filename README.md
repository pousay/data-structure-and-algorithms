# Data Structures & Algorithms

A learning repository for **Data Structures and Algorithms**, based on *Data Structures and Algorithm Analysis in C++ (4th Edition)* by Mark Allen Weiss.

This repository contains:

* **Study Notes** — concise explanations and concept summaries.
* **C++ Implementations** — practical implementations of data structures and algorithms.
* **Analysis** — time and space complexity, correctness, and problem-solving techniques.
* **Exercises** — solutions and experiments throughout the book.
